# DATA-ANALYTICS-USING-SQL
This project consists of various SQL scripts for Data exploration, analytics and reporting, which covers various analysis like Database Exploration, measures &amp; metrics, cumulative analysis, time based trends etc. This will help Data and Business Analyst  to quickly explore, segment and analyze data within a relational database.


DATA-ANALYTICS-USING-SQL-project/
│
├── Data_Sets/                           # Contains bronze,silver,gold data sets
│
├── docs/                               # Project roadmap details
│   ├── Advance Analytics Roadmap.pdf   # Shows the roadmap for doing advance analytics on the cleaned data set(gold tables)
│   ├── EDA Roadmap.pdf                 # Shows the roadmap for doing Exploratory Data Analysis on the cleaned data set(gold                                            tables)

├── scripts/                            # SQL scripts for Advance_Analytics, EDA along with Reports
│   ├── Advance_Analytics/              # Scripts for doing advance analysis like cumulative, performance analysis etc.
│   ├── Exploratory_Data_Analysis/      # Scripts for doing Exploratory Data Analysis like Database, Dimension,Date                                                     exploration etc
│   ├── Reports/                        # Scripts for creating customers and products reports
│
│
├── README.md                           # Project overview and instructions
